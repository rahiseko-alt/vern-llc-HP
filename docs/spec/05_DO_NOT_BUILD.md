# 05 — STOP LIST / これは違うから止めろ

**最重要ファイル。コーディングAIはこれを破ったらやり直し。**

## 絶対に禁止

### 1. サイバーパンク化
- neon
- cyan / magenta
- glow
- hologram
- scanline
- digital noise

**違う。**

### 2. ターミナル化
- 黒背景 + 緑文字
- CLI UI
- blinking prompt
- monospace全面

**違う。**

### 3. Windows 95 / GeoCities / pixel retro
- pixel font
- bevel button
- browser chrome parody
- desktop icons

**違う。**

### 4. VHS / CRT / glitch
- RGB split
- VHS tracking
- glitch transition
- chromatic aberration常用

**違う。**

### 5. Generic SaaS化
- rounded cards
- pill buttons大量
- gradient blob
- pricing-card構成
- blue/purple AI gradient
- dashboard grid

**最悪。絶対に違う。**

### 6. Brutalist webに逃げる
- 意味のない極太sans
- 画面一杯の巨大英字だけ
- intentionally ugly
- 原色

このサイトは「雑なブルータリズム」ではなく、**編集・組版された知性**。

### 7. カントの肖像画を主役にする
肖像・胸像をhero中央に置かない。
哲学者紹介サイトにしない。

### 8. 古紙エフェクトをやりすぎる
- 破れ
- 焦げ
- stain
- sepia全面
- heavy grain

「アンティーク加工」ではない。

### 9. 全部動かす
- 全headlineにanimation
- 常時marquee
- 常時parallax
- cursor trail常時
- loading animation長時間

静けさを壊す。

### 10. custom cursorを主役にする
小さな補助なら可。
巨大な円カーソル、遅延しすぎるカーソルは不要。

### 11. scroll-jacking
スクロール操作を奪わない。
セクションスナップを強制しない。

### 12. WebGL自慢
3Dだから使う、shaderだから使う、は不可。
技術が見えるより、思想が見えること。

### 13. fake archive
存在しない引用、偽のカント語録、意味のないドイツ語を生成しない。
一次資料と創作を混ぜない。

### 14. text effectの品評会にしない
1ページで10種類のエフェクトを見せない。
同じmotion grammarを繰り返す。

## 判定基準

画面を静止させたときに
「Awwwardsのテンプレ」ではなく
「非常に良く組まれた思想書・研究誌・古い学術印刷物」
に見えること。
