# 08 — Acceptance Checklist

## Visual
- [ ] screenshotだけでも成立する
- [ ] 紙 / 活版 / 学術誌の空気がある
- [ ] カテゴリー表が構造として生きている
- [ ] SaaSテンプレ感がない
- [ ] 肖像画頼みではない

## Motion
- [ ] REASON → VERNUNFT flipが滑らか
- [ ] flip解除も滑らか
- [ ] typewriterがterminal化していない
- [ ] proximity liftが「丘」のようにつながる
- [ ] ink revealが光らない
- [ ] 常時動く要素が少ない

## Technical
- [ ] desktop 60fps目標
- [ ] mobileで破綻しない
- [ ] touchでhover依存しない
- [ ] prefers-reduced-motion対応
- [ ] keyboard focusで意味が欠落しない
- [ ] 本文をcopy/selectできる
- [ ] WebGLを切ってもコンテンツが読める

## Taste test

以下の質問にYESなら合格。

1. 画面を印刷して壁に貼っても成立するか？
2. エフェクトを全部止めても美しいか？
3. 動きが「技術デモ」ではなく意味を持っているか？
4. 触った瞬間だけ現代Webだとわかるか？
5. 「レトロ」ではなく「時代を超えた編集デザイン」に見えるか？
